# Publicar a demonstração da Vitrine

1. Descompacte este ZIP.
2. No repositório `draphossites/Vitrine`, selecione **Add file → Upload files**.
3. Arraste o conteúdo extraído para a raiz do repositório. O `index.html` deve aparecer ao lado do `README.md`, junto às pastas `demo/` e `vitrine-pages-assets/`. Clique em **Commit changes**.
4. Se necessário, abra **Settings → Pages** e selecione **Deploy from a branch**, `main` e `/(root)`. Depois da publicação, abra o endereço do GitHub Pages.

Esta página é a demonstração pública do projeto. A sacola finaliza uma simulação local. O botão **Acessar o sistema da Vitrine** leva para a Vitrine hospedada no Sites, onde estão o cadastro, o painel do lojista e o Adimin.
